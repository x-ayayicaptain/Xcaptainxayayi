X-AYAYI.DE — IONOS LIVE V2 / ADSENSE READY
===========================================

Upload this package directly into the X-AYAYI domain target directory on IONOS.
The archive is flat: index.html is in the ZIP root.

WHAT IS INCLUDED
-----------------
- 80-product shop with gallery, cart and direct checkout UI
- Server-side checkout endpoints (credentials stay server-side)
- Root fallback endpoints /checkout.php and /chat.php
- Health endpoint /health.php
- AdSense publisher meta tag + consent-gated AdSense loader
- ads.txt
- robots.txt + sitemap.xml
- 404 page
- Impressum / Datenschutz / AGB / Widerruf / Versand & Rückgabe / Kontakt / Cookies
- Original shop guide /ratgeber.html
- ADSENSE_SETUP.txt with the remaining Google account steps

IMPORTANT BEFORE SALES / ADSENSE
---------------------------------
1. Replace all [PLACEHOLDER] legal/business information in the legal pages.
2. Configure the actual payment provider credentials on the IONOS server.
   Never put secret API keys into HTML or JavaScript.
3. In Google AdSense add/verify x-ayayi.de and configure Privacy & Messaging.
4. For personalized ads in the EEA, UK and Switzerland, use the Google-required
   certified TCF CMP (or the Google CMP available in AdSense). The included
   consent gate prevents the AdSense script from loading before an optional
   advertising consent, but it does NOT itself certify the site as a TCF CMP.
5. Add the exact privacy-policy URL in AdSense: https://x-ayayi.de/datenschutz.html
6. Verify https://x-ayayi.de/ads.txt after deployment.
7. Check actual product stock, prices, shipping, tax treatment, image rights and
   brand permissions before taking live orders.
8. Google AdSense approval is not guaranteed; Google performs its own review.

IONOS PERMISSIONS
-----------------
Typical current IONOS defaults are 755 for directories and 644 for files.
Do not use 777.

SECURITY
--------
- No payment/API secret is included in this ZIP.
- Checkout and optional AI support are server-side.
- Temporary diagnostic files were removed from the public package.
